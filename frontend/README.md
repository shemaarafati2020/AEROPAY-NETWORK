# AeroPay Network - Frontend Client

High-performance cross-border remittance application powered by React Native, Expo SDK 54, and Stellar Soroban.

## Features

- 🚀 **Sub-Second Remittance Flow**: Instant mobile money payouts into MTN MoMo, Airtel Money, and M-Pesa.
- 🎨 **iOS-Inspired Glassmorphism**: OLED Dark Mode, dynamic cards, and haptic animations.
- 🛡️ **Role-Based Operations Console**: Comprehensive Admin Supervisor portal with real-time push broadcasts, gas relayer monitoring, and KYC management.
- 🤖 **AI Remittance Assistant**: Intent classification, route optimization, and proactive fee forecasts.

## Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Start Expo development server
npm run start

# Run Web platform
npm run web
```

### Docker

```bash
# Build docker image
docker build -t aeropay-frontend .

# Run container
docker run -p 8080:80 aeropay-frontend
```
